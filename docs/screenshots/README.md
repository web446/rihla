# Screenshots

The screenshots used by the main README, taken from the running site with the sample data.
To retake one, keep the same file name:

| File | What it shows |
|---|---|
| `home.png` | Homepage (hero, boarding-pass search, postcards) |
| `country.png` | A country page with the "With a Lebanese passport" card |
| `checkout.png` | Trip basket or simulated checkout |
| `trips.png` | My Trips with a "BOOKED" stamp |
| `guide.png` | Guide dashboard (log in as guide@rihla.test) |
| `admin.png` | Admin dashboard (log in as admin@rihla.test) |
| `mobile.png` | Any page on a phone (browser dev tools, device mode) |

Tip: in Chrome press F12, then Ctrl+Shift+P and run "Capture full size screenshot".
